# Product definition

Ankora is a local-first desktop visual workbench for step-by-step molecular docking and virtual screening across **Windows 11 x64** (`private_beta`) and **Linux x86\_64** (`release_candidate`, Ubuntu 24.04 LTS reference baseline; awaiting bare-metal physical workstation Gate `D6`). It removes mechanical CLI friction while preserving explicit scientific inspection and decision-making. See [`PLATFORM_STATUS.md`](PLATFORM_STATUS.md) for the exact platform and engine capability matrix.

The primary user is a scientifically literate docking practitioner. Commands, parameters, warnings, intermediate files, tool identities, and SHA-256 provenance remain visible at every step. Ankora never treats computational docking scores as experimental binding free energy or predicted poses as proof of biological activity.
