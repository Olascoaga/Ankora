# Scope

Version 0.1 covers structure import and read-only inspection (`PDB`, `mmCIF`, RCSB, AlphaFold DB), user-controlled receptor and ligand-library preparation for local virtual-screening campaigns, interactive 3D binding-site definition (including local `P2Rank 2.5.1` pocket detection), independent multi-engine docking execution, durable pose/cluster review, in-place crystallographic redocking validation, reproducible campaign export, record-derived `Methods` generation, and exact-pose `ProLIF` interaction analysis.

On **Windows 11 x64** (`private_beta`) and **Linux x86\_64** (`release_candidate`, Ubuntu 24.04 LTS reference under `ADR-026` and `ADR-029`), Ankora supports `AutoDock Vina 1.2.7`, `AutoDock4 4.2.6` (CPU, over immutable `AutoGrid4 4.2.6` maps), and `AutoDock-GPU 1.6` (`OpenCL` on Windows; multi-architecture `CUDA 12` on Linux). On **Linux x86\_64**, Ankora additionally supports `GNINA 1.3.3` (`ADR-027`, `ADR-028`) for single-ligand and sequential library virtual screening (`CPU` or `CUDA 12.8`, `rescore` and CUDA-only `refinement`, built-in `dense_1_3`, `default_1_3_ensemble`, and `default1.0` CNN models, plus `CNNscore` and `CNN_VS` hit prioritization), delivered as an optional 1-click GUI-imported offline runtime pack alongside the Core `.deb` and zero-`sudo` `.tar.zst` bundles (`ADR-029`). GNINA remains deferred on native Windows, and final Linux release acceptance remains gated on bare-metal physical workstation attestation (`ADR-029` Gate `D6`; see [`PLATFORM_STATUS.md`](PLATFORM_STATUS.md)).

`M1–M9` implement the complete path from immutable input through explicitly controlled docking, durable `Results`, redocking `Validation`, portable `Export`, and exact-pose `ProLIF` interaction analysis (`docs/validation/M9_POSE_INTERACTIONS.md`).

Cloud or remote/HPC execution, million-compound screening, macOS, merged cross-engine consensus scoring, molecular dynamics, custom user-uploaded neural weights, and automated chemical decisions remain out of v0.1 scope. Local batch controls may apply an explicitly confirmed preparation or docking protocol across a library, but never resolve stereochemical, protonation, or tautomer microstates silently.
