Use a create-only isolated copy of the previously prepared 1HSG/MK1 project and
the pinned GNINA 1.3.3 executable. Verify all declared hashes. The experimental
single-job service must reject remapped CUDA visibility, MIG, multiple GPUs and
logical indices other than 0. On a system with one unambiguous GPU, run device
0 with two CPU threads, seed 20261029, exhaustiveness 1 and two poses. Require
the enumerated GPU UUID to match the UUID observed for the GNINA process,
successful topology-checked results, unchanged original inputs and resource
release. Preserve raw output and failure evidence. This WSL run is not proof of
per-operation GPU inference, general multi-device support, GUI behavior or a
scientific benchmark.
