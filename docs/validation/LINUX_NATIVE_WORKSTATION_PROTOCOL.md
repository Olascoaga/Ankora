# Native Linux Workstation Verification Protocol (`ADR-029` Gate `D6`)

## Scope and scientific boundary

This protocol defines the bare-metal Linux workstation release gate (`D6` in
[ADR-029](../architecture/ADR/ADR-029-linux-offline-distribution.md)) for the
Ankora `0.1.0` Linux x86-64 offline packages.

WSL2/WSLg clean-room execution (`D4`, recorded in
`docs/validation/LINUX_OFFLINE_PACKAGE_SMOKE.md`) exercises the packaged ELF
binaries, bundled scientific runtimes, and GPU pass-through under Microsoft's
WSL2 kernel (`/usr/lib/wsl/lib`), which is engineering evidence rather than
bare-metal Linux workstation acceptance. Final Linux release sign-off requires
executing this protocol on a physical `x86_64` Linux workstation running a
native Linux kernel with a native NVIDIA driver (`>= 570.x` recommended for
CUDA 12.8 compatibility) and a native X11 or Wayland desktop session.

This gate verifies packaging, runtime isolation, legal/source completeness, GPU
device binding, and offline GNINA pack import. It does not alter or extend
Ankora's frozen scientific benchmark claims in `VALIDATION_STATUS.md`.

## Required release files

Copy the release folder generated by `scripts/build_linux_installer.py` (plus
`scripts/smoke_linux_package.py` from the repository) onto the physical Linux
workstation:

1. `Ankora_0.1.0_amd64.deb` — Core offline Debian/Ubuntu installer (Tauri
   desktop shell, bundled Python 3.12.13 scientific backend, AutoDock Vina
   `1.2.7`, AutoGrid4/AutoDock4 `4.2.6`, multi-arch AutoDock-GPU `1.6`, Eclipse
   Temurin OpenJDK `21.0.12.1+1`, P2Rank `2.5.1`, and complete third-party legal
   notices).
2. `Ankora_0.1.0_linux_x86_64.tar.zst` — Zero-`sudo` portable offline archive
   for shared university/HPC workstations.
3. `Ankora_0.1.0_gnina-cuda12-pack.tar.zst.part01` + `.part02` (from GitHub
   Releases, each `< 2.0 GiB`) or single-file `Ankora_0.1.0_gnina-cuda12-pack.tar.zst`
   — Optional offline GNINA `1.3.3` + CUDA `12.8` + cuDNN `9.25` runtime pack
   (`17` user-space shared libraries, NVIDIA/GPL notices, and SHA-256 manifest).
4. `Ankora_0.1.0_linux-sources-companion.zip` — Corresponding GPL/LGPL source
   archive companion.
5. `SHA256SUMS.txt` and `linux-release-manifest.json`.

## Step 1 — Verify checksums before installation

In the folder containing the release files:

```bash
sha256sum -c SHA256SUMS.txt
```

Every file must report `OK`.

## Step 2 — Install the `.deb` package

On Ubuntu 24.04 LTS, Linux Mint 22, Pop!\_OS, or Debian:

```bash
sudo apt install ./Ankora_0.1.0_amd64.deb
```

Alternatively, double-click `Ankora_0.1.0_amd64.deb` in the desktop Software
Center and click **Install**. Confirm that **Ankora** appears in the desktop
application menu (`/usr/share/applications/ankora.desktop`).

Disconnect network access (or switch to Airplane Mode) before proceeding so
offline operation is attested directly.

## Step 3 — Interactive desktop & 1-click GNINA pack check

1. Launch **Ankora** from the desktop launcher (or run `ankora`).
2. Confirm the header status pill reports **Backend connected** and the
   **Tools -> Scientific tools** view reports `Bundled Python 3.12` and all ten
   Core tools (`PDBFixer`, `PDB2PQR`, `PROPKA`, `Meeko receptor`, `Meeko ligand`,
   `P2Rank`, `AutoDock Vina`, `AutoGrid4`, `AutoDock4`, and `AutoDock-GPU`) as
   available, while `GNINA` is initially not installed.
3. Click **Import offline GNINA pack...** (in **Tools -> Scientific tools** or
   inside **Docking -> GNINA**) and select
   `Ankora_0.1.0_gnina-cuda12-pack.tar.zst.part01` (with `.part02` in the same folder, or single-file `.tar.zst`) in the native file dialog.
4. Confirm `GNINA 1.3.3` transitions immediately to **Installed / Ready**
   without restarting Ankora or setting `PATH` / `LD_LIBRARY_PATH`.
5. Close Ankora before running the automated attestation harness in Step 4 so
   loopback port `127.0.0.1:8765` is free.

## Step 4 — Automated bare-metal workstation attestation (1 command)

Run the zero-dependency standard-library attestation script using the system
Python 3.12 interpreter:

```bash
/usr/bin/python3 scripts/smoke_linux_package.py \
  --native-workstation-attestation \
  --gnina-pack ./Ankora_0.1.0_gnina-cuda12-pack.tar.zst.part01
```

What this command enforces automatically:

- **WSL rejection:** Refuses to run if `/proc/version` or `uname -r` indicates
  a Microsoft/WSL kernel.
- **Installed package audit:** Verifies `dpkg -s ankora`, legal notice SHA-256
  integrity under `/usr/lib/ankora/legal/`, intra-bundle symlinks, and absence
  of forbidden host driver libraries (`libcuda.so*`, `libnvidia-ml.so*`) inside
  the Core tree.
- **Clean-environment cold start:** Launches `/usr/bin/ankora` with
  `PATH=/usr/bin:/bin`, `LD_LIBRARY_PATH` unset, and an isolated temporary
  `HOME` / `XDG_DATA_HOME`; verifies loopback-only listener binding on
  `127.0.0.1:8765`.
- **10/10 Core scientific matrix:** Executes
  `/usr/lib/ankora/backend/ankora-backend --worker native-smoke` across all ten
  Core adapters including `AutoDock-GPU` on the native NVIDIA GPU.
- **Offline GNINA pack import + CPU/CUDA docking:** Imports
  `Ankora_0.1.0_gnina-cuda12-pack.tar.zst` via `POST /api/v1/tools/gnina-pack/import`
  into the isolated `XDG_DATA_HOME`, prepares the fixed `1VII` villin +
  synthetic ethanol smoke inputs, and executes four real jobs (`Vina`,
  `GNINA` CPU `rescore`, `GNINA` CUDA `rescore`, and `GNINA` CUDA `refinement`
  with `default_1_3_ensemble` and live `nvidia-smi` GPU process UUID
  verification).
- **Clean shutdown:** Sends `SIGTERM` to `ankora-desktop` and verifies both the
  desktop shell and child `ankora-backend` terminate cleanly and close port
  `8765`.

## Step 5 — Record bare-metal attestation

Retrieve the generated `native-workstation-attestation.json` file (and its
printed `attestation_sha256`) from the `ankora-native-workstation-attestation-*`
folder and record the bare-metal workstation kernel, NVIDIA driver version, GPU
model, and `attestation_sha256` to close Gate `D6`.
